# Totoro Totem

A Minecraft resource pack that replaces the Totem of Undying with a 3D Totoro, by **ohhellokira**.

## What's included

| Pack | Description |
|------|-------------|
| **Totoro Totem** | A small standalone pack. It only swaps the totem for Totoro and works with vanilla. |
| **Kira's_3D_Items_Totoro** | with the Totoro totem built in. Use it instead of the original 3D Items pack. |

## Where Totoro appears

- First-person and third-person hand
- Inventory (GUI)
- Dropped on the ground
- Item frames

## Installation

1. Download the pack you want from the [Releases](../../releases) page.
2. Put the `.zip` in your `resourcepacks` folder (don't unzip it).
3. Enable it in **Options → Resource Packs**.

Pick one pack, not both. The full 3D Items pack already includes Totoro. If you use both, put `Totoro_Totem_Only` above the 3D Items pack.

## Compatibility

Built for Minecraft Java Edition resource pack formats 46–128 (1.21.5 and up, including 26.1).
